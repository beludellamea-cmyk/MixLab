# MIXLAB – Misión Mezclas

Recursos digitales para la clase de Físico-Química de 1.º año de secundaria (mezclas homogéneas y heterogéneas), pensados con criterios de Diseño Universal para el Aprendizaje (DUA) y accesibilidad.

## Contenido

- `acompanante/index.html`: **Acompañante de clase**. Reproduce el contenido del Anexo A para leer, escuchar, ampliar imágenes, explorar las tres mezclas y repasar. Incluye ajustes de lectura (tamaño, tipo de letra, espaciado, fondos, alto contraste, regla de lectura, voz lenta, una parte por vez). Es un solo archivo HTML; para verlo localmente alcanza con abrirlo en el navegador.

## Estado de accesibilidad

Diseñado para reducir barreras (dislexia, baja visión, altas capacidades). Todavía no se validó con lectores de pantalla, navegación solo con teclado ni estudiantes reales.
